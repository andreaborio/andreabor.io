## Retrieval contract

- Use this index to select one note; do not ingest the full corpus by default.
- Prefer each note's retrieval capsule in its Markdown URL before loading the full body.
- `Estimated context` is a byte-based token estimate for budgeting, not a tokenizer-exact count.
- Treat `status`, `evidence`, and `claim boundary` as normative.
- Do not promote a hypothesis, structural fixture, or pinned-not-supported path into a runtime support claim.
- Preserve exact dimensions, hashes, revisions, and arithmetic when a note marks them as closed.
- Cite the canonical HTML URL when presenting a note to humans.
- This corpus contains public architecture only. It excludes personal information, subscriptions, account details, credentials, private prompts, conversations, local paths, network addresses, and unpublished infrastructure.
